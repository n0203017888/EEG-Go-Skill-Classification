# EEG 圍棋棋力分類 — 專案總覽

> 用傳統機器學習(以 SVM 為主)從 EEG 腦波訊號分類圍棋選手的棋力等級。
> 本文件由整份專案的 notebook、結果 JSON/CSV 與圖檔彙整而成。

---

## 1. 一句話總結

**用 EEG 的「功能連結(PLV)」+「頻帶能量(BE)」兩種特徵,經腦區分群 → PCA 降維 → SVM-RBF 分類,可以有效區分圍棋棋力三個等級(amateur / master / prof)。**
其中 **頂葉(Parietal)區 + 三個 session 軟投票** 效果最好,達 **Acc 0.946 / F1 0.943**(就是你那張截圖)。

---

## 2. 研究任務與資料

| 項目 | 內容 |
|------|------|
| 任務 | 3 類分類:`amateur`(業餘低段) / `master`(業餘高段) / `prof`(國手) |
| 受試者 | 57 人(amateur 28、master 21、prof 8) |
| 總 trials | 5,096 筆 |
| 取樣率 / 通道 | 500 Hz / 常用前 32 通道 |
| Trial 長度 | 21 秒(10,500 samples) |
| Session | 3 個階段:ss01 開局、ss02 中盤、ss03 尾盤 |

> 類別數量不均(prof 只有 8 人),因此評估同時看 **Accuracy 與 Macro-F1**。

---

## 3. 特徵設計(核心)

你沒有直接餵原始波形給模型,而是抽了兩類生理意義明確的特徵,並分成 5 個頻帶(delta / theta / alpha / beta / gamma):

| 特徵 | 全名 | 意義 | 維度 |
|------|------|------|------|
| **PLV** | Phase Locking Value(相位鎖定值) | 通道之間的**功能連結 / 同步性**(32×32 連結矩陣 × 5 頻帶) | 每腦區數十~180 維 |
| **BE** | Band Energy(頻帶能量) | 各通道在各頻帶的**頻譜能量**(反映該頻段活化程度) | 每腦區 15~45 維 |

**Pipeline:**
```
EEG → PLV / BE 特徵 → 依腦區分群 → PLV、BE 各自做 PCA(保留 95% 變異)→ 合併 → SVM-RBF
     → session 層級預測 → 同一受試者 3 個 session 做多數決(硬投票 / 軟投票)
```

**腦區分群(REGIONS):** Frontal(7ch)、Central、Parietal(9ch)、Temporal、Occipital(3ch)。
→ 各腦區單獨跑,結果 **Parietal(頂葉)一路領先**。

---

## 4. 最佳結果 ⭐(對應你的截圖)

**腦區 = Parietal,特徵 = PLV + BE 合併,分類器 = SVM-RBF**

| 評估層級 | N | Accuracy | Macro-F1 |
|----------|----|----------|----------|
| Session-level(每個 session 各算一次) | 168 | 0.839 | 0.838 |
| **Hard Vote**(3 個 session 硬投票) | 56 | 0.929 | 0.929 |
| **Soft Vote**(3 個 session 機率軟投票) | 56 | **0.946** | **0.943** |

**結論:把同一位受試者三個 session 的預測合併(投票),準確率從 84% 大幅拉升到 93~95%** —— 這是專案最重要的發現之一。軟投票略優於硬投票。

> 檔案:`SVM_PLV/svm_plv_be_combined.ipynb`、`svm_parietal_majority_vote.png`

## 5. 你做過的其他測試(依主題整理)

### 5.1 多分類器比較(Parietal, PLV+BE)
比較 11 種分類器,**SVM-RBF 是全場最強**:

| 分類器 | Session Acc | Hard Vote | Soft Vote |
|--------|:-----------:|:---------:|:---------:|
| **SVM-RBF** | **0.839** | **0.929** | **0.946** |
| ExtraTrees | 0.810 | 0.857 | 0.929 |
| KNN-5 | 0.762 | 0.893 | 0.929 |
| RandomForest | 0.738 | 0.804 | 0.786 |
| LightGBM | 0.732 | 0.839 | 0.875 |
| GradBoost / XGBoost | ~0.71 | ~0.76 | ~0.79 |
| LogReg / LDA / GaussianNB / MLP | 0.50~0.63 | — | — |

並用 **McNemar + Wilcoxon 檢定(Holm 校正,α=0.05)** 驗證顯著性:

- **沒有顯著差異**(兩種檢定皆未達標):ExtraTrees(McNemar p=0.383)、**KNN-5(p=0.052)**
- **部分顯著**(McNemar 達標、Wilcoxon 未達標):RandomForest、GradBoost(皆 p=0.058)
- **顯著**:其餘六種模型

→ SVM-RBF 數值上領先,但**相對 ExtraTrees 與 KNN-5 的優勢在統計上並不成立**,三者應視為同一梯隊。
→ 檔案:`ML_PLV_BE/ml_plv_be_compare.ipynb`、`pvalue_analysis.ipynb`、`ml_plv_be_pvalues_vs_svm.csv`

### 5.2 腦區比較(單特徵)
| 特徵 | 最佳腦區 | Acc |
|------|----------|-----|
| 只用 PLV | Parietal | 0.738 |
| 只用 BE | Parietal | 0.708 |
| **PLV + BE 合併** | **Parietal** | **0.839** |

→ 兩種特徵**互補**,合併明顯優於單用其一;且頂葉區資訊量最高。
→ 檔案:`SVM_PLV/svm_plv.ipynb`、`SVM/svm_band_energy.ipynb`

### 5.3 頻帶消融(Band Ablation,Parietal)
- **基準(全 5 頻帶)**:Acc 0.839
- **LOBO(每次拿掉一個頻帶)**:拿掉 gamma → 0.863、拿掉 theta → 0.851(反而變好)→ 代表 **gamma / theta 貢獻最小**;拿掉 beta(→0.804)、delta(→0.810)最傷 → **beta / delta 最關鍵**。
- **單頻帶**:beta 0.780 > alpha 0.768 > delta 0.756 > theta 0.738 > gamma 0.679。
- **最佳頻帶子集**:`{delta, alpha, beta}` → **0.863**(比用全部還高)。

→ 檔案:`SVM_PLV/svm_band_ablation.ipynb`、`svm_band_ablation_results.json`

## 6. 沒成功的測試(誠實記錄,同樣有價值)

你嘗試用 EEG 特徵**迴歸預測行為/表現指標**,**三者都失敗,但失敗的方式不同**:

| 目標 | 資料夾 | Pearson r | 結果 |
|------|--------|-----------|------|
| 勝率 winrate | `winrate_predict/` | −0.001~0.079(p>0.13) | 純粹隨機,無任何訊號 |
| 勝步 winstep | `winstep_predict/` | −0.074~0.059(p>0.24) | 純粹隨機,無任何訊號 |
| 反應時間 RT(毫秒) | `RT1_ms_predict/` | 0.19~0.44(**p<0.001**) | 相關顯著但 **R² 為負**,見下 |

> ⚠️ **RT 的相關性是假象。** 三個證據:(1) R² 全為負(−0.05~−0.22),比直接猜平均值還差;
> (2) 預測值幾乎是常數——各 subject 的預測平均只落在 22.1~22.3 秒,而實際平均橫跨 21.6~39.3 秒;
> (3) master 內部 LOSO 得到 **r=−0.363(p<0.0001)**,符號翻轉。
> 跨群的正相關來自群體間分布差異,而非模型對個別 trial 的判斷。
> 這是「統計顯著但實質無意義」的典型案例,只看 p 值會得出完全相反的結論。

**結論:EEG 特徵能區分「棋力等級」(分類成功),但無法預測單場的「即時表現數值」(迴歸失敗)。** 這其實是個合理且值得寫進論文的負面結果 —— 說明這些特徵捕捉的是**穩定的個人特質/專業度**,而非**當下的表現波動**。

---

## 7. 一句話帶走的重點

1. **最佳配置**:Parietal + PLV+BE + SVM-RBF + 三 session 軟投票 → **Acc 0.946**。
2. **投票是關鍵增益**:session 層級 84% → 投票後 93~95%。
3. **PLV 與 BE 互補**,合併才強;頂葉區資訊量最高。
4. **beta / delta 頻帶最重要**,gamma 幫助最小。
5. **SVM-RBF 在傳統模型中最強**,且經統計檢定驗證。
6. **分類成功、迴歸失敗** → 特徵反映的是長期棋力,不是即時表現。
