# Test1 分腦區 (5區) 分類流程

## ① 資料讀取

- 讀取 amateur / master / prof 三組受試者的 `.mat` 檔（band_energy），每組各有 ss01/ss02/ss03 三個 session
- 篩選出三個 session 都完整的受試者：amateur 28 人、master 20 人、prof 8 人（共 56 人）
- 每筆原始資料 shape：`(32ch, 39 timepoints, 5 bands)`

## ② 通道分 5 腦區

```
Frontal (7ch):   Fp1, Fp2, F3, F4, F7, F8, Fz
Central (7ch):   C3, C4, Cz, FC1, FC2, FC5, FC6
Parietal (9ch):  P3, P4, P7, P8, Pz, CP1, CP2, CP5, CP6
Temporal (6ch):  T7, T8, FT9, FT10, TP9, TP10
Occipital (3ch): O1, O2, Oz
```

## ③ 特徵提取（每個 session 各自處理，不跨 session 平均）

- 去掉時間軸頭尾各 1 個 timepoint
- 對剩下的時間點取平均 → 每個 session 得到 `(32ch, 5bands)` 的特徵向量
- 56 人 × 3 session = **168 筆樣本**，堆疊成 `(168, 32, 5)`

## ④ 依腦區切出特徵並展平

- 例如 Frontal：取 7 個通道 × 5 band → 展平成 `35 維`
- 5 個腦區分別做，各自獨立跑一次完整流程

## ⑤ LOSO（Leave-One-Subject-Out）交叉驗證

- 每一輪留一位受試者（他的 3 個 session 一起）當測試集，其餘 55 人（165 筆）當訓練集
- 56 輪，每人輪流當一次測試對象

## ⑥ 每一輪內：標準化 → PCA → SVM

1. `StandardScaler`：使用Z-score標準化,套用到訓練/測試集
2. `PCA(n_components=0.95)`：保留 95% 解釋變異量，各自降維到（Frontal→7、Central→8、Parietal→7、Temporal→6、Occipital→4）

# Test2 對 F,C,P,O,T 的 ss01,ss02,ss03 分別擾動 (BE)

## ① 資料讀取與特徵提取

- 讀取方式與 Test1 完全相同：56 人（amateur 28、master 20、prof 8）× 3 個 session，log 轉換 + 去頭尾時間點 + 時間平均 → 每個 session 得到 `(32ch, 5bands)`

- 差別是**額外保留「依 session 分開」的結構**：`feats_3d_by_session`，長度為 3 的 list，每個元素 shape 為 `(56, 32, 5)`，方便之後針對「單一 session」做擾動

## ② Baseline（未擾動基準）

- 對 5 個腦區，各自跑一次標準 LOSO 分類（`StandardScaler → PCA → SVM`）
- 跟Test1一樣 `PCA(n_components=0.95)`：保留 95% 解釋變異量

## ③ 擾動設計：針對「單一 session」做隨機排列 (permutation)

1. 複製一份三個 session 的特徵資料
2. **只對被指定的那個 session**，把 56 個人的特徵向量順序隨機打亂（`np.random.permutation`），讓這個 session 的腦電資料錯配到別人的身分標籤上（相當於把這個 session 攜帶的個人資訊破壞成雜訊）
3. 另外兩個 session 維持原樣、標籤也維持原樣
4. 用打亂後的資料重建成跟 Test1 相同排列方式的 `(168, 32, 5)` 陣列
5. 重新跑一次完整 LOSO 分類流程，得到擾動後的 Acc / F1

## ④ 重複 30 次取平均（N_REPEATS = 30）

- 每個「腦區 × session」組合，用 30 個不同的 random seed 各做一次隨機排列與分類，取 Acc / F1 的平均值與標準差，避免單一次隨機排列的偶然性影響結論

# 附錄：PCA 計算原理

## ① 標準化（Standardization）

對每個特徵：
```
x' = (x − μ) / σ
```
讓每個特徵平均為 0、標準差為 1，避免不同量綱的特徵互相影響。這一步由 `StandardScaler` 完成，**sklearn 的 `PCA` 本身只會做「置中」（減去平均值），不會除以標準差**。

**奇異值分解 SVD :**
```
X = U · S · Vᵀ
```
- U：n×n 正交矩陣
- S：對角矩陣，對角線是奇異值 s₁ ≥ s₂ ≥ ... ≥ 0
- V：d×d 正交矩陣，每一欄就是主成分方向

兩者關係：`λᵢ = sᵢ² / (n−1)`，V 的欄向量跟方法 A 的特徵向量是同一組方向。sklearn 用 SVD 是因為不用先算共變異數矩陣，數值上更穩定。
